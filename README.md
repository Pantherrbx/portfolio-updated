- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Run locally

Make sure Node.js and npm are installed, then run:

```bash
git clone https://github.com/Pantherrbx/portfolio-updated.git
cd portfolio-updated
npm install
npm run dev
```

Vite will print the local URL in the terminal after the development server starts.
